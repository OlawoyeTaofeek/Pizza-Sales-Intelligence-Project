# 🍕 Pizza Sales Intelligence Project

## Overview
This project simulates a real-world data platform for a fictional pizza company. It demonstrates the complete data engineering and analytics workflow from ingestion to dashboarding using modern tools.

## Objectives
- Automate ingestion of raw pizza orders into PostgreSQL using Airflow.
- Move data into Snowflake for scalable analytics.
- Perform transformations with DBT to create a star schema.
- Use Databricks for advanced analytics (e.g., elasticity, seasonal trends).
- Build a Power BI dashboard to present insights.

## Tech Stack
- **Airflow** for orchestration
- **PostgreSQL** as raw staging DB
- **Snowflake** for analytics
- **DBT** for transformations
- **Databricks (PySpark)** for analytics
- **Power BI** for visualization

# 🚀 Getting Started

## Prerequisites

- Python 3.10+
- Docker (for Airflow)
- Snowflake account
- Data Build Tool(DBT)
- Databricks community account 
- Power BI Desktop

## Getting Started
1. Load CSVs into PostgreSQL using `load_csv_to_postgres.py`
2. Run Airflow DAG to move data to Snowflake
3. Run DBT models: `dbt run`
4. Open Power BI dashboard connected to Snowflake
